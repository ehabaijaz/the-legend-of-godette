# What is this?
- A prototype for an open world 3d game in which the player has been developed and a small demo room to play with different features.
- No AI used

# Controls
- WASD for movement
- Spacebar for Jump
- Right click button for block
- Left click button for attack
- Middle mouse button for change weapon
- CTRL to run


# Features
- Unique animations for each movement and action
- Ability to do a double attack
- You can interrupt attacks with another attack or a block or even changing your weapon. Try mixing different movements and actions and see how they flow together smoothly.
